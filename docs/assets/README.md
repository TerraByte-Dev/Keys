# Assets

`keys-icon.png` is the master: 1024x1024, transparent, keyed from a render that came
back on flat chroma green because the image model could not output an alpha channel.
**Every other size is cut from it by `tools/make_icons.py`** -- do not hand-edit the
derivatives, recut them:

    .venv\Scripts\python tools\make_icons.py            # recut from the master
    .venv\Scripts\python tools\make_icons.py fresh.png  # key and adopt a new render

That produces `frontend/icon-32|180|512.png` (favicon and touch icon),
`docs/assets/keys-icon-256.png` (this README's hero) and `packaging/keys.ico`
(seven sizes, 16 to 256, for the executable and the taskbar).

The design is the app's own palette and its one rule: **amber means sounding.** Four
cream keys, two black, and the second white key lit from within -- a keybed with a note
in it. Near-black tile `#0E1013`, keys `#D9D4C6` and `#15171B`, lamp `#FFA62B`.

`screenshots/` is taken from the running app; see `screenshots/README.md`.
`terrabyte-logo.png` is the company mark and is not generated by anything here.
